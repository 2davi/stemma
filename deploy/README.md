# deploy

배포 구성과 운영 절차를 둔다. 제공자(AWS 또는 Google Cloud)와 도구는 배포 구성 결정 기록에서 정한다.

## 1차 구성

| 구성 요소 | 선택 |
| --- | --- |
| 애플리케이션 서버 | 가상 머신 한 대에 `stemma-api`와 `account-api` |
| 데이터베이스 | 같은 가상 머신 안의 PostgreSQL. 데이터베이스 `stemma`와 `account` |
| 오브젝트 스토리지 | 관리형 (S3 또는 Cloud Storage) |
| 정적 프런트엔드 | 오브젝트 스토리지와 CDN |
| 인증서 | 클라우드 제공자의 무료 인증서 |

## 이름 규칙

버킷 이름은 코드네임이 아니라 도메인을 따른다(`the2davi-media` 같은 꼴). 버킷 이름은 전역에서 유일해야 하고, 만든 뒤에는 바꿀 수 없다.

## 운영 원칙

같은 기계에서 직접 돌리는 데이터베이스는 백업이 자동으로 돌고 복구를 한 번 이상 실제로 해 본 뒤에만 유지한다.
