# stemma-web

Stemma의 React 프런트엔드다.

## 진입점

읽기 화면과 편집 화면은 성격이 완전히 달라서 진입점을 처음부터 나눈다. 글 하나 읽는 방문자가 편집기 코드를 내려받지 않게 하려는 것이다. 빌드 결과는 정적 파일이라 오브젝트 스토리지와 CDN으로 낸다.

## 이름

| 자리 | 값 |
| --- | --- |
| 패키지 이름 | `@2davi/stemma-web` |
| 테마 CSS 사용자 지정 속성 | `--stemma-` 접두사 |
| 브라우저 저장소 키 | `stemma:` 접두사 |

패키지 이름을 [스코프](https://docs.npmjs.com/about-scopes) 아래 두는 이유는 공개 npm에 `stemma`라는 패키지가 이미 있어서다. 스코프 없는 내부 패키지 이름은 같은 이름의 공개 패키지가 대신 설치되는 의존성 혼동(dependency confusion)의 빌미가 된다.

테마용 사용자 지정 속성은 사용자 테마가 기대기 시작하는 순간 공개 규약이 된다. 이름은 7단계(테마와 레이아웃) 전에, 사용자 CSS의 범위를 정하는 결정 기록과 함께 확정한다.

브라우저 저장소 키에 접두사를 붙이는 이유는 the2davi.dev 아래 다른 화면과 같은 출처(origin)를 나눠 쓰게 될 때 키가 섞이지 않게 하려는 것이다.

## 편집기 원칙

블록 하나가 `contenteditable` 요소 하나다. 한글 조합 중(`compositionstart`부터 `compositionend`까지)에는 상태 갱신과 다시 그리기를 막고, 조합이 끝난 시점에만 상태에 반영한다. 되돌리기는 모든 편집 조작을 명령 객체로 만들어 직접 쌓는다.
