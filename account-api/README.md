# account-api

회원 서비스다. 가입, 로그인, 프로필, 탈퇴를 맡고, 회원 정보가 바뀌면 같은 트랜잭션 안에서 아웃박스에 이벤트를 쓴다.

## 이름

| 자리 | 값 |
| --- | --- |
| 기본 패키지 | `dev.the2davi.account` |
| 애플리케이션 이름 | `account-api` |
| 설정 접두사 | `account.*` |
| 환경 변수 접두사 | `ACCOUNT_` |
| 데이터베이스 | `account` |
| 데이터베이스 역할 | `account_app`은 데이터만, `account_migrator`는 구조 변경만 |

## 코드네임을 달지 않는 이유

이 서비스는 블로그 전용이 아니다. 나중에 만들 다른 서비스가 같은 회원 기반 위에 서게 하려고 블로그와 가른 것이라, 이름은 엔진이 아니라 도메인(`dev.the2davi`)을 따른다. 지금은 이 저장소 안에 있지만 나중에 떼어 내도 이름을 바꿀 일이 없다.

## 구현 원칙

바깥으로 내보내는 식별자는 부르는 이름(`@handle`) 하나다. 계정 식별자는 만들어진 시각을 담고 있어서 내보내면 가입 시각이 샌다.

탈퇴는 행을 지우지 않고 익명화로 처리한다.

스키마 변경 파일은 이 모듈 안에 둔다.
