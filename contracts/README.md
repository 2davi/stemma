# contracts

회원 서비스와 블로그 엔진이 주고받는 이벤트의 계약이다. 두 서비스가 공유하는 유일한 접점이라, 서비스의 독립은 데이터베이스를 나눴다는 사실보다 이 계약을 판본으로 관리하는 데서 나온다.

## 이름 규칙

이벤트 타입에는 코드네임을 넣지 않는다. 지금 설계의 `account.created`, `account.renamed`, `account.deactivated`처럼 적고, [CloudEvents](https://cloudevents.io) 관례를 따를 때는 앞에 `dev.the2davi`를 붙인다. 나중에 다른 서비스가 구독할 이름이라서다. 브로커를 끼울 때 생길 토픽 이름도 같은 규칙을 따른다.

## 판본 규칙

필드를 지우거나 뜻을 바꾸는 변경은 새 판본으로 내고, 옛 판본을 한동안 함께 발행한다. 판본은 이벤트 본문이 아니라 아웃박스의 `schema_version` 컬럼에 적는다.

## 파일 규칙

계약 파일의 형식은 첫 이벤트를 만들 때 정한다. 파일 이름은 `{이벤트 타입}.v{판본}` 꼴로 맞춘다. 예를 들면 `account.created.v1`이다.
